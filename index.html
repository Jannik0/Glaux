Get Glaux How to use

Open models

Any open-weights model, ready to run

Pick a model from Hugging Face, download it through Glaux, and start using it. If it is published as Safetensors or GGUF, Glaux can serve it locally — chat, vision, and speech included. No need to tinker around or set up extra software; Glaux manages everything for you.

Safetensors

Full open models

The standard weights format on Hugging Face. Use it when you want the complete open-weights model for chatting, looking at images, or transcribing speech.

GGUF

Compact open models

Smaller packaged versions of the same open models. Choose a GGUF build when you want capable AI that fits more comfortably on your machine.

Some Hub models are gated. Accept the license on the model page, then set a Hugging Face access token in your environment before you open Glaux.

Use cases

Everyday work, kept private

Glaux is a workspace for people who want local AI for writing, files, and recordings — not a developer toolkit.

Chat without uploading your notes

Draft emails, outline ideas, and talk through a problem the way you would with a cloud assistant — except the conversation stays on your computer. Sessions are saved in your workspace so you can pick up later.

Ask about what is in an image

Drop a photo or screenshot into the chat when the model supports images. Describe a scene, extract text from a picture, or ask what is happening — useful for receipts, whiteboards, and everyday snapshots.

Turn speech into text

Attach a voice memo, meeting recording, or video. Glaux can transcribe the audio on your machine so you get a written record without sending the file to a transcription service.

Read documents, then ask questions

PDFs are turned into readable text automatically. Drop in an invoice, form, or report and ask for totals, names, or a short summary — the file never leaves your workspace.

Keep work in its own workspace

Each workspace has its own chats, resource library, and outputs. Switch workspaces when you change projects so files and conversations do not mix.

Everything you need to download a model, talk to it, and keep the files that come out of that work.

How to use

From install to first conversation

You do not need any prior experience running AI models. Simply follow these steps in the app to get started.

  1. Download the installer for your system, run it, and launch Glaux from the Start menu, Applications, or your desktop shortcut. No extra runtimes to install.

  2. The header shows the active workspace. Stay on Default, or create a new one for a project. Each workspace keeps its own chats and files.

  3. In the Models panel, paste a Hugging Face model id such as org/model-name and choose Add. Glaux fetches any open-weights Safetensors or GGUF model you pick. For GGUF you can choose a smaller or larger variant before the download starts.

  4. Click the downloaded model to load it. Type in the input field at the bottom of the chat window and send. A context meter shows how much of the model’s memory the conversation is using.

  5. Drag images, audio, video, or PDFs into the your message in order to pass them to the model. Use a vision model for pictures, a speech model for recordings, or attach a PDF to ask about the document.

  6. Sessions holds past conversations. Resources is your project library. Outputs collects files you export or generate. Everything is saved under your user profile on your computer.

On your machine

Chats, files, and models stay with you at all times

Glaux runs models on your computer. Sessions, resources, and outputs live in your user profile. Model files are stored on disk after you download them — they are not uploaded for someone else to host. If your machine has a compatible GPU, Glaux uses it automatically; otherwise it falls back to the CPU.

Get Glaux

Install the desktop app

The current public installer is for Windows. Models are downloaded after you install — they are not inside the setup file. A GPU driver helps when you want faster responses, but it is not required.

Download for Windows All releases

Windows 10 or 11. Run the setup, choose a folder if you like, then open Glaux from the Start menu.
